Favori « FCI → registre »

Sur la page LINE d'un dossier, il lit le FCI dans les commentaires et prépare la commande pour le registre.

FCI → registre
  1. Affiche la barre de favoris (Ctrl+Maj+B), puis glisse le bouton vert ci-dessus dedans. À faire une fois, dans Chrome et/ou dans Firefox.
  2. Ouvre la page LINE d'un dossier (menu ⋯ du registre › Accès LINE).
  3. Clique sur le favori FCI → registre : il copie fci NIO301548-THF010 F99496231124.
  4. Dans le registre : Ctrl+V puis Entrée. Le FCI est à jour (annulable avec cancel).

Le favori ne lit que la page que tu as ouverte, et n'envoie rien nulle part.
