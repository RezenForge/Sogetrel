Favori « FCI → registre »

Sur la page LINE d'un dossier, il lit le FCI dans les commentaires et prépare la commande pour le registre.

FCI → registre
  1. Affiche la barre de favoris (Ctrl+Maj+B), puis glisse le bouton vert ci-dessus dedans. À faire une fois, dans Chrome et/ou dans Firefox.
  2. Ouvre la page LINE d'un dossier depuis le registre : menu ⋯ › Accès LINE chrome.
  3. Clique sur le favori FCI → registre : le FCI est mis à jour directement dans le registre (annulable avec cancel).
  4. Page LINE ouverte autrement (Firefox, favori, lien) : le favori copie fci NIO301548-THF010 F99496231124 ; Ctrl+V puis Entrée dans le registre.

Le favori ne lit que la page que tu as ouverte, et n'envoie la commande qu'au registre qui l'a ouverte.
